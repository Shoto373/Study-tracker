# Study Tracker

Небольшое приложение, чтобы вести учёбу: список предметов, записи о том, сколько времени ушло на занятия, и дедлайны. На главной видно, сколько часов набралось за неделю по каждому предмету и как это соотносится с целью.

Проект учебный, делается для себя.

## Что умеет

- Предметы: название, цвет и недельная цель в часах.
- Сессии: когда и сколько занимался, с короткой заметкой.
- Дедлайны: что сдать и до какого числа. Просроченные подсвечиваются, выполненные можно отметить.
- Блок «Эта неделя»: часы с понедельника по каждому предмету и полоска прогресса к цели.

Группу можно выбрать вверху страницы: предметы подтянутся из расписания РГРТУ (rasp.rsreu.ru). Группа запоминается на сервере за вашим IP, и при следующем заходе выбирается сама. Данные у каждого IP свои.

Если сменить группу, старые предметы заменяются предметами новой. Если на каких-то предметах уже записано время, сайт сначала спросит подтверждение, потому что вместе с предметами удалятся занятия и дедлайны.

Удаление предмета удаляет и его сессии с дедлайнами.

## Стек

- Бэкенд: FastAPI, SQLAlchemy, SQLite.
- Фронтенд: React 19, TypeScript, Vite, Tailwind CSS 4.

## Запуск

Нужны Python 3 и Node.js. Бэкенд и фронтенд запускаются отдельно.

Бэкенд:

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

API поднимется на http://127.0.0.1:8000, документация по маршрутам будет на `/docs`. База `study_tracker.db` создаётся сама в папке, из которой запущен сервер, поэтому запускать нужно из `backend/`.

Фронтенд:

```bash
cd frontend
npm install
npm run dev
```

Откроется на http://localhost:5173.

## API

Для каждого из ресурсов `/subjects/`, `/sessions/` и `/deadlines/`:

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/<ресурс>/` | список |
| POST | `/<ресурс>/` | создать |
| PUT | `/<ресурс>/{id}` | заменить запись целиком |
| DELETE | `/<ресурс>/{id}` | удалить |

## Тесты

```bash
cd backend
pip install -r requirements-dev.txt
pytest
```

Тесты идут на in-memory SQLite, рабочая база не затрагивается.

## Структура

```
backend/    FastAPI: модели, схемы, маршруты
frontend/   React-приложение
```

Адрес бэкенда прописан в `frontend/src/api/client.ts`, а разрешённый источник для CORS в `backend/main.py`. Если меняете порты, поправьте оба места.
